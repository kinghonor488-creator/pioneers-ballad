## 1. 开始游戏

### 1.1 需要准备什么

- 一台电脑（主要在 macOS 上测试过）
- 免费的游戏引擎 **Godot 4**（4.7 测试通过）。macOS 上可以在终端里运行 `brew install --cask godot` 安装

### 1.2 启动游戏

| 方式 | 怎么做 |
| --- | --- |
| **最简单（macOS）** | 双击项目文件夹里的 **拓荒者之歌.app**。刚从 GitHub 下载的话还没有这个文件，先在项目文件夹里运行一次 `bash tools/make_launcher.sh` 生成它。可以把它拖到程序坞里，以后一点就开 |
| 终端 | 在项目文件夹里运行 `godot --path .` |
| Godot 编辑器 | 打开 Godot → 导入项目文件夹里的 `project.godot` → 按 **F5** |

### 1.3 创建第一个世界

启动后先看到**标题界面**：

- **选择世界**：列出你所有的世界（名字、第几天、大小、玩了多久、上次保存时间）。点一下进入，旁边的「删除」会先问你确认。
- **创建新世界**：
  - **名字**：随便起，不填就叫「新世界 1」
  - **种子**：同一个种子永远生成同一个世界。留空就是随机；填数字或者任何文字都行（比如填「我的生日」，朋友填同样的字就能得到一模一样的世界）
  - **大小**：小（1600×600）、中（2800×900）、大（4200×1200）。**第一次玩建议选「中」**，世界没那么大，容易找到各种地方

点「创建并进入」，大约 1 秒生成完世界，你就站在世界正中间的森林里了。

## 2. 操作按键

| 按键 | 作用 |
| --- | --- |
| **A / D** 或 **← / →** | 左右走。遇到一格高的台阶会自动跨上去 |
| **空格 / W / ↑** | 跳。按得越久跳得越高。**在水里按住是往上游** |
| **鼠标左键（按住）** | 使用快捷栏里选中的东西：拿镐/斧就挖，拿方块就放，拿药水就喝，拿炸弹就扔，拿武器就攻击 |
| **鼠标右键 / Q** | 把选中的东西丢出去 1 个；按住 **Shift** 丢出整堆 |
| **1 ~ 0**、**鼠标滚轮** | 选择快捷栏的第 1 ~ 10 格 |
| **E / Tab / I** | 打开或关闭背包和制作栏 |
| **Esc** | 关闭背包；没开背包时打开暂停菜单（保存、回标题、退出） |
| **F11 / Ctrl+Cmd+F / Alt+Enter** | 切换全屏 |

**背包打开时：**

| 操作 | 作用 |
| --- | --- |
| 左键点格子 | 拿起 / 放下 / 交换。同种东西会叠在一起 |
| 拿着东西点背包外面 | 把它丢到地上 |
| 右键点背包里的饰品 | 直接戴上 |
| 左键点制作栏里的图标 | 制作 |
| 鼠标指着制作栏滚动滚轮 | 制作栏放不下时翻页 |

## 3. 看懂界面

```
┌────────────────────────────┐                      ┌──────────────┐
│ ① 快捷栏 1 2 3 … 0          │                      │ ⑥ 生命 ▇▇▇▇▇ │
└────────────────────────────┘                      │    法力 ▇▇▇▇ │
  ② 选中的道具名                                     │ 第 1 天 07:12 │
                                                    │ 森林·地表·海拔│
                                                    │ ✧ 增益 / ✖ 负面│
                                                    └──────────────┘
                    （中间是世界：你、方块、敌人、掉落物）

  ④ 消息（捡到了什么、受了伤、制作了什么……）
  ⑤ 操作提示                                              FPS
                    ③ Boss 血条（Boss 战时才出现）
```

1. **快捷栏**：背包的前 10 格。选中的格子有金色边框。格子左上角的 **★数字** 是这件工具或武器的熟练度等级。
2. **选中的道具名**：名字的颜色就是它的稀有度（见 7.1）。
3. **Boss 血条**：显示 Boss 的名字、血量，进入二阶段时会标出来。
4. **消息**：右下角往上滚动，几秒后消失。
5. **操作提示**：一行小字，忘了按键时看一眼。
6. **状态区**（右上角）：
   - 红条是**生命**，蓝条是**法力**；有防御时旁边会显示「防御 N」
   - 第几天、几点
   - 你在哪里：生物群系 · 层 · 海拔或深度（1 格 = 0.5 米）
   - 身上的效果：蓝色 ✧ 是增益（比如喝了药水），红色 ✖ 是负面效果（中毒、冻伤），后面是剩余秒数

**鼠标指着任何格子都会弹出说明**：名字、稀有度、各种数值、词缀、熟练度、怎么用。指着制作栏的图标还会列出需要的材料（够的是绿色、不够的是红色）和要在哪个制作站旁边做。

**鼠标指向的方块**有一个方框：白色表示够得着，红色表示太远。挖的时候方块上会出现裂纹，裂得越多越快挖开。

## 4. 新手第一天：一步一步来

开局你有：**燧石镐、燧石斧、燧石短剑、15 个火把、3 个苹果**。早上 7 点开始，大约 10 分钟后天黑。

**第 1 步：砍树（白天，约 2 分钟）**
选中燧石斧（按 2），走到树旁边，对着**树干最下面**按住左键。整棵树会倒下来，木材掉在地上，走过去自动捡起。砍 3～4 棵树，攒 **30 个以上木材**。

**第 2 步：做工作台**
按 **E** 打开背包，在制作栏里找到「工作台」（10 个木材），点它。关掉背包，在快捷栏选中工作台，对着平地点一下放下来。

**第 3 步：站在工作台旁边做东西**
离工作台 5 格以内，制作栏会多出很多配方：
- **火把**（徒手也能做：1 个木材 = 3 个火把）
- **木剑**（7 个木材，比燧石短剑强一点）
- 想要的话做一把**木弓**（10 个木材）和**箭矢**（1 个木材 + 1 个石块 = 25 支）

**第 4 步：往下挖，找石头和赤铜矿**
选中燧石镐，对着脚下按住左键往下挖。几格泥土之后就是**石头**。每挖下去几格，**放一个火把**（选中火把，点墙边），地下很黑。
你会看到带**橙红色斑点**的方块，那是**赤铜矿**。挖它！

**第 5 步：做熔炉，炼赤铜锭**
在工作台旁边做**熔炉**（20 个石块 + 4 个木材 + 3 个火把），放下来。站在熔炉旁边，3 个赤铜矿炼成 1 个**赤铜锭**。

**第 6 步：升级装备**
在工作台旁边：
- **赤铜镐**（8 个赤铜锭 + 3 个木材）——能挖**铁矿**了
- **赤铜剑**（7 个赤铜锭）

**第 7 步：准备过夜**
晚上（大约 19 点以后）地面上会出现**游魂**。它能穿过地面上的树和墙，所以躲在地面的小屋里没用；但它**钻不进地下**——最简单的办法是：
- **往下挖 5 格以上**，在地下的小洞里放几个火把，继续挖矿。游魂够不着你，过一会儿就会放弃离开
- 第一天晚上怪物不会变多，是熟悉战斗的好机会

**生命低了就吃苹果**（选中苹果，左键）。如果倒下了也不用怕：3 秒后在出生点复活，**背包里的东西一件都不会丢**。

> 小贴士：打开背包，鼠标指着制作栏里**灰色的**配方，能看到还差什么材料、要在哪个制作站做——这是找下一个目标最快的办法。

## 5. 这个世界

### 5.1 从上到下的分层

| 层 | 大约在哪 | 有什么 |
| --- | --- | --- |
| **天空** | 地面以上很高的地方 | 空的 |
| **地表** | 地面附近 | 草地、树、湖泊；白天安全，晚上有游魂 |
| **地下** | 地面往下一段 | 石头夹着泥土，隧道、赤铜矿、铁矿、蘑菇、水潭 |
| **洞穴层** | 世界一半左右往下 | 大溶洞、月银矿、星辉矿、灵晶簇、**水晶洞**，开始有熔岩 |
| **深渊** | 接近世界底部 | 黑色的玄武岩、大片空洞、**熔晶矿**、很多熔岩、余烬魔 |
| **基岩** | 最底下几格 | 无法破坏 |

越往下越危险，但矿越好、宝匣开出的东西也越好。右上角会显示你现在在哪一层。

### 5.2 生物群系

出生点在世界正中间的**森林**。往两边走会遇到不同的地方：

| 生物群系 | 在哪 | 特点 |
| --- | --- | --- |
| **森林** | 中间 | 普通的草地和树，最安全 |
| **沙漠** | 森林和其中一边之间 | 厚厚的沙子，没有树；沙子能烧玻璃 |
| **雪原** | 世界的一边，**一直延伸到地下深处** | 雪块、**很滑的冰**、雪松；霜狼和冰灵会让你**冻伤** |
| **丛林** | 世界的另一边，**一直延伸到地下深处** | 泥浆、丛林草、巨大的丛林树、藤蔓、发光的孢子花；黄蜂和毒刺花会让你**中毒** |
| **水晶洞** | 洞穴层里的几个大洞 | 发蓝光和粉光的晶石墙，地上长满灵晶簇，墙里有**虹晶矿** |

雪原和丛林在世界的哪一边是随机的。

### 5.3 白天和黑夜

- 游戏里**一天 = 现实 12 分钟**。新世界从早上 7 点开始。
- 大约 **5 点天亮、7 点全亮、17 点开始变暗、19 点天黑**。日出日落时天空和光线是橙色的，夜里是蓝色的月光。
- 夜里地面上会出现**游魂**（能穿过地面上的东西，但钻不进地下），从第二天晚上开始地面上的怪物也会更多。地下没有昼夜之分，一直是黑的。

### 5.4 遗迹宝匣

地下散布着发金光的**遗迹宝匣**（大世界里大约 70 个）。用镐把它挖开，宝物会蹦出来掉在地上：
- 一件主要奖励：常常是**饰品**，也可能是稀有工具或武器，或者一组药水
- 2～4 件其他东西：火把、药水、炸弹、各种锭、灵晶碎片、箭矢……
- **越深的宝匣越好**
- 在**雪原、丛林、水晶洞**里的宝匣，有一半几率开出当地特产
- 炸弹炸不坏宝匣，放心炸

## 6. 挖掘与建造

### 6.1 怎么挖

选中镐或斧，对着方块**按住左键**。工具会一下一下地挥动，每一下都会溅出碎屑；方块上出现裂纹，裂满了就碎了，挖到的东西掉在地上，走近就会自动捡起来。

- **够得着的距离**：以你为中心 **5 格**。有些东西能加长：「远触的」词缀、延伸臂环（+2）、旅者星核（+1）、星辉镐和熔晶钻头（+1）
- **徒手**也能慢慢挖软的东西
- **镐**挖土石和矿，**斧**砍树（木头类的方块，比如树干、木板、工作台，用斧更快）
- 挖得越快、挥得也越快：更好的镐、熟练度、「迅捷的」词缀、矿工手套、采掘药水都能加快

### 6.2 镐的等级（最重要的进度）

每种方块都有一个「需要的镐等级」。镐的等级不够，挖的时候只会溅出火星，提示「需要镐等级 N」。

| 镐 | 等级 | 能挖什么 |
| --- | --- | --- |
| 燧石镐 | 1 | 泥土、石头、沙子、赤铜矿、硫磺石…… |
| 赤铜镐 | 2 | ＋铁矿、晶石 |
| 铁镐 | 3 | ＋月银矿、玄武岩、黑曜石、虹晶矿 |
| 月银镐 / 古代遗镐 | 4 | ＋星辉矿 |
| 星辉镐 | 5 | ＋熔晶矿（**要先打败灵晶守望者**，见第 11 章） |
| 熔晶钻头 | 6 | 一切能挖的东西 |

所有工具的数据见 [16.3 工具](#163-工具)，所有方块的硬度和需要的等级见 [16.5 方块](#165-方块)。

### 6.3 砍树

对着**树干**砍，从砍的地方往上**整棵树都会倒下来**，一次拿到所有木材。树叶里有几率掉**苹果**。砍倒大树时屏幕会震一下。

### 6.4 放置方块

选中方块或家具，对着空的地方左键：
- 普通方块：旁边要有别的方块，或者后面有**背景墙**（不能凭空悬在半空）
- **火把**：要贴着方块或背景墙
- **工作台、熔炉、铁砧、蘑菇**：下面要有方块托着
- 不能把方块放在自己身上；火把这类东西不能放进水里
- 实心方块放进水里会把水挤掉

背景墙是地下自带的，挖掉方块后还会留着；地面附近和深渊没有背景墙。

### 6.5 光照

每一格都有自己的亮度：
- **天光**从天上照下来，能顺着洞口照进去一段，但照不透厚土层；挖开地面阳光就照进来，在头顶盖屋顶会挡住阳光
- 往下挖竖井时，**井口亮、越往下越暗**（每往下一格天光弱一些，十几格以下就基本照不到了），深处还是要靠火把
- 光在空气里传得远，在方块里很快变暗——火把能照亮洞壁表面，但照不到墙后面
- **发光的东西**：火把（最亮，暖黄色）、灵晶簇（青色）、熔炉、遗迹宝匣（金色）、晶石和虹晶矿、孢子花（绿色）、熔岩和熔晶矿（橙色）；游魂、余烬魔、Boss、法术弹、爆炸也会照亮周围
- 你自己身上有一点点光；**萤石项链**、**萤光药水**、**虹光棱镜**、**守望之眼**、**旅者星核**能让它更亮

**地下没有光的地方是全黑的，下矿一定要带够火把。**

## 7. 道具系统

这是本作最有特色的部分。

### 7.1 稀有度

每件道具都有稀有度，名字和格子边框的颜色会跟着变：

| 稀有度 | 颜色 |
| --- | --- |
| 普通 | 白 |
| 优良 | 绿 |
| 稀有 | 蓝 |
| 史诗 | 紫 |
| 传说 | 橙 |
| 神话 | 红 |

稀有度 ≥「稀有」的东西掉在地上会发一点光，比较好找。

### 7.2 词缀

**每次做出一把工具或武器（或者从宝匣、Boss 那里拿到），都会随机带上一个词缀**，比如「迅捷的铁镐」「致命的星辉剑」。词缀会改变数值，也会改变稀有度：好词缀让稀有度升一两档，坏词缀（比如「笨重的」「钝的」）会降一档。大约 1/3 的情况没有词缀。

所有词缀和出现几率见 [16.6 词缀](#166-词缀)。

### 7.3 重铸

不满意词缀？站在**铁砧**旁边，把工具或武器放在快捷栏选中，打开背包，点制作栏下面的「**重铸选中工具/武器的词缀**」，花 **2 个灵晶碎片**重新随机一个。可以一直重铸到满意为止。

### 7.4 熟练度

工具**挖得越多**、武器**打得越多**，熟练度就越高（最高 Lv5）：每升一级，挖掘力或伤害 **+6%**。快捷栏格子左上角的 ★ 数字就是等级，升级时会有提示。

- 工具：每挖碎一个方块得到经验（越硬的方块经验越多）
- 武器：每打中一次得 1 点，打死敌人得 5 点

所以**用顺手的武器别随便扔**。经验表见 [16.7 熟练度](#167-熟练度)。

### 7.5 饰品

背包右边有 **3 个饰品格**。把饰品放进去才会生效（背包里右键饰品可以直接戴上）。同一种饰品只能戴一个，不同饰品的效果会**叠加**。

饰品能提供：移动速度、跳跃力、挖掘速度、触及距离、照明、免疫摔落伤害、最大生命、防御、伤害、暴击率、法力上限、水下呼吸、熔岩减伤、免疫中毒、免疫冻伤、冰上不打滑、拾取范围……全部饰品见 [16.2 全部道具](#162-全部道具) 的「饰品」部分。

**推荐的新手饰品**：羽落护符（再也不怕摔）、疾风靴（跑得快）、萤石项链（下矿不用一直放火把）。它们都在遗迹宝匣里。

### 7.6 药水和增益

喝了药水会得到一段时间的**增益**（右上角显示 ✧ 和剩余秒数），和饰品效果叠加：

| 药水 | 效果 |
| --- | --- |
| 治疗药水 | 立刻回 60 点生命 |
| 萤光药水 | 照明 +6，持续 4 分钟 |
| 迅捷药水 | 移动速度 +30%，3 分钟 |
| 采掘药水 | 挖掘速度 +35%，4 分钟 |
| 跃升药水 | 跳跃力 +35%，3 分钟 |
| 水息药水 | 在水下自由呼吸，5 分钟 |
| 再生药水 | 每秒回 3 点生命，2 分钟 |
| 解毒剂 | 立刻解除中毒和冻伤 |

吃东西或喝药水回血后，要等 **8 秒**才能再回一次；生命满的时候吃不了。

其他好用的消耗品：
- **回城卷轴**：立刻传送回出生点，迷路必备
- **生命果**：永久增加 20 点最大生命，**最多吃 5 个**
- **炸弹 / 烈性炸药**：扔出去 2 秒后爆炸，炸开半径 3 格 / 5 格的方块（**炸掉的方块不会掉落**，也会伤到离得近的你）

### 7.7 掉落物

挖出来的东西、打怪掉的东西、宝匣里的东西，都会先**掉在地上**，在地上轻轻浮动。走到大约 **3.5 格**以内就会被吸过来自动捡起（戴**磁石戒指**再远 5 格也能吸）。

- 同一个地方掉的同种东西会合成一堆
- **背包满了**东西就留在地上，腾出位置后再走过去就能捡
- 想丢东西：右键或 Q（Shift 丢整堆），或者背包里拿着它点背包外面。**自己丢的东西要过 1.2 秒才会被吸回来**
- 地上的东西会跟着存档一起保存

## 8. 生存

### 8.1 生命

- 初始最大生命 **100**。生命果（每个 +20，最多 5 个）、活力护符、泥王之心能加
- **6 秒没受伤**后会自动回血（每秒 2 点）
- 生命归零就倒下，**3 秒后在出生点复活，背包里的东西一件都不丢**。周围的怪物会被清掉，身上的负面效果也会消失

### 8.2 各种伤害

| 来源 | 伤害 | 怎么防 |
| --- | --- | --- |
| 怪物碰到你、怪物的弹幕 | 见敌人图鉴 | **防御**：每点防御减少 0.5 点伤害（至少扣 1）。受伤后有 0.6 秒无敌时间，并被击退 |
| **摔落** | 从高于 **22 格**的地方掉下来，每多一格扣 6 点 | 羽落护符完全免疫；**掉进水里不会摔伤** |
| **溺水** | 憋气用完后每秒扣 10 点 | 见 8.4 |
| **熔岩** | 每 0.6 秒扣 30 点（不受防御减免） | 熔火护符减少 70%；水能把熔岩变成黑曜石 |
| **中毒** | 每秒 3 点 | 苦根护符免疫；解毒剂解除 |
| 自己的炸弹 | 10～40 点 | 扔远一点 |

### 8.3 法力

法杖每次施法消耗法力（蓝条，初始 40）。停止施法 1.2 秒后开始恢复，每秒恢复 12 点。灵泉坠饰 +20 法力上限。

### 8.4 憋气

头在水下时，头顶会出现一排**气泡**，能憋 **10 秒**；气泡用完就开始溺水。离开水面气泡会很快恢复。
- **潜水呼吸管**：憋气时间变成 3 倍
- **水息药水**：5 分钟内在水下自由呼吸

### 8.5 负面效果

| 效果 | 谁会造成 | 影响 | 怎么办 |
| --- | --- | --- | --- |
| **中毒** | 丛林黄蜂、毒刺花的种子 | 每秒掉 3 点血 | 苦根护符免疫；解毒剂解除 |
| **冻伤** | 霜狼、冰灵 | 走路慢 35%，跳得矮 25% | 毛皮围巾免疫；解毒剂解除 |

### 8.6 冰面

雪原的**冰**很滑：起步慢、停不下来，小心滑进坑里。**冰爪鞋**能让你在冰上不打滑。

## 9. 战斗

### 9.1 三类武器

| 类型 | 怎么用 | 特点 |
| --- | --- | --- |
| **近战**（剑、短剑、大剑、战锤） | 按住左键连续挥砍 | 挥砍有范围，一刀能砍中多只怪。**按着方向键时往移动方向砍**（挥到一半掉头，剑也跟着转）；不按方向键时朝鼠标那一边 |
| **弓**（木弓、铁弓、星辉长弓、虹晶连弩、棱光弩） | 朝鼠标方向射箭 | **需要背包里有箭矢**，每射一支消耗一支；箭会往下坠，远处要往上瞄一点。弓的伤害 + 箭的伤害；灵晶箭能穿透 3 个敌人 |
| **法杖**（幽光、冰霜、淤泥、炎爆、棱晶法杖） | 朝鼠标方向施法 | **消耗法力**；法术弹走直线、不受重力影响，能穿透多个敌人，还会照亮路过的地方 |

武器也有**词缀**（锋利的、迅疾的、致命的、沉重的、狂暴的、传奇的……）和**熟练度**，可以在铁砧**重铸**。

### 9.2 伤害是怎么算的

```
伤害 = 武器伤害（弓还要加上箭的伤害）
       × (1 + 词缀加成 + 熟练度加成 + 饰品和药水的伤害加成)
       × 暴击时翻倍
       × 0.9～1.1 的随机浮动
       − 敌人防御的一半          （最少 1 点）
```

- **暴击率**：基础 4%，加上武器、词缀、猎手护目镜、虹光棱镜、守望之眼。暴击的伤害数字是**金色**的，带「!」
- **击退**：打中会把敌人打退，「沉重的」词缀和大剑、战锤击退更强；有些硬的怪（岩甲虫、灵晶傀儡、Boss）很难被击退
- **毒刺短剑**打中会让敌人**中毒**（持续掉血，敌人会变成绿色）

### 9.3 怪物从哪来

- 怪物会在**屏幕外**（离你 26～44 格的地方）刷出来，种类取决于你在**哪一层、哪个生物群系、白天还是夜晚**
- 同时存在的怪物上限：地表白天 3 只，夜里最多 7 只（**第一天晚上照顾新手，还是 3 只**）；地下一直是 7 只；Boss 战时只有 2 只小怪
- 离你太远（75 格以上）的怪会自动消失；天亮后，只在夜晚出现的游魂也会离开

### 9.4 打法建议

- 被围的时候往后退，让怪排成一排再砍
- 会穿墙的怪（冰灵、水晶幽影、余烬魔）躲不掉，要正面打；**游魂**例外——它钻不进地下，躲到地下 5 格以上就安全了
- 毒刺花不会动，用弓在远处射它
- 夜里在地表待着很危险，可以先往下挖，在地下挖矿，等天亮再上来

## 11. Boss 战

Boss 不会自己出现，要用**召唤道具**叫出来。召唤后屏幕中间会出现大字公告，底部出现 **Boss 血条**。Boss 血量低于一半时会**被激怒，进入二阶段**，攻击更凶。

- 你**倒下**或者**跑得太远**（约 110 格），Boss 就会离开，召唤道具不退回
- Boss 不会被击退
- 击败 Boss 会**自动存档**，暂停菜单里能看到你击败过哪些 Boss
- 同一个 Boss 可以反复召唤、反复打，每次都会掉落

### 11.1 泥沼巨像

| | |
| --- | --- |
| **召唤** | 在**地表**使用「泥沼祭品」（工作台：15 个泥核 + 5 个木材；泥核是打泥团怪掉的） |
| **推荐装备** | 铁剑或铁弓，最好有几瓶治疗药水 |
| **数据** | 生命 900，碰撞伤害 22，防御 4，泥浪伤害 16 |

**它会做什么：**
- 一下一下**跳向你**；**落地时向左右两边掀起泥浪**，泥浪贴着地面走，能爬台阶、会掉进坑里——**看到它落地就跳起来**躲泥浪
- **每跳三下有一次高高跃起的重砸**，落地时屏幕震得很厉害
- 被地形卡住或离你太远时会**钻进地里**（血条上显示「钻进了地里」），过一会儿从你身边钻出来
- **二阶段**：跳得更快、泥浪更快，重砸时还会叫出两只泥团怪

**打法**：找一块平坦开阔的地，站在它跳过来的路线外侧。它在空中时砍它或射它，它落地前跳起来躲泥浪。

**掉落**：泥王之心（饰品：最大生命 +20、防御 +3）、6～10 个巨像碎片（做「巨像壁垒」，防御 +7）、2～4 瓶治疗药水、**随机一把**泥沼战锤或淤泥法杖。

### 11.2 灵晶守望者

| | |
| --- | --- |
| **召唤** | 在**洞穴层或深渊**使用「灵晶信标」（铁砧：15 个灵晶碎片 + 5 个月银锭 + 3 个幽光尘） |
| **推荐装备** | 月银剑或更好的武器，一些治疗药水；能穿墙的攻击（法杖）也很好用 |
| **数据** | 生命 2600，碰撞伤害 30，防御 10，晶刺伤害 20 |

**它会做什么：**
- 一直**绕着你飞**，经常飞在石头里面
- 每隔一会儿放出**一圈晶刺**，**这圈晶刺能穿过岩石**
- 身体**发光闪烁**时就是要冲刺了，接着会**朝你猛冲过来**——看到闪光就往旁边跑或跳
- **二阶段**：晶刺更多（12 根）、冲刺更快，而且会**从头顶降下晶刺雨**。晶刺雨**会被天花板挡住**，可以找个头顶有石头的地方躲

**打法**：在一个比较大的洞里打，留出躲冲刺的空间。二阶段时靠近洞顶低的地方，躲晶刺雨。

**掉落**：守望之眼（饰品：暴击 +10%、照明）、3～5 个**守望者棱晶**、3～5 瓶治疗药水、**随机一把**棱晶法杖或棱光弩。

**守望者棱晶非常重要：星辉镐和星辉剑都需要它。** 不打败灵晶守望者，就拿不到星辉镐，也就挖不了熔晶矿。

## 12. 水和熔岩

### 12.1 液体会流动

世界里有**地表湖泊**、**洞穴水潭**，洞穴层以下还有**熔岩池**。它们一开始是静止的；你挖开一个口子，液体就会流出来：往低处走、铺平、从悬崖边流下去。熔岩流得比水慢。

每一格液体分 8 份高度，没满的格子会显示出水面高低。水是半透明的，能看见水里的东西。

### 12.2 水 + 熔岩 = 黑曜石

水碰到熔岩，熔岩会**凝固成黑曜石**。黑曜石很硬（要铁镐才能挖），是做**熔火护符**的材料。被熔岩挡路时，倒一桶水过去就能变成路。

### 12.3 桶

- **空桶**（工作台：3 个赤铜锭）：对着水或熔岩点一下，装起来（附近至少要有半格的量）
- **水桶 / 熔岩桶**：对着空的地方点一下，倒出一整格
- 可以用来自己造水池、把熔岩引过来、或者灭熔岩

### 12.4 在液体里

- 下沉很慢，走得慢，**按住跳跃键往上游**
- 头在水下会**憋气**（见 8.4）
- 熔岩会烫伤你（见 8.2），但会把周围照亮

## 14. 存档、窗口与设置

### 14.1 存档

- **每 5 分钟自动保存**一次；**关闭游戏窗口时也会自动保存**
- 想马上保存：按 **Esc** → 「保存游戏」，或者「保存并回到标题界面」「保存并退出游戏」
- 会保存：世界里的每一个方块和液体、背包、饰品、手上拿着的东西、地上的掉落物、药水效果和剩余时间、工具和武器的词缀和熟练度、生命果、位置、生命、天数和时间、击杀数、击败过的 Boss
- 存档位置（macOS）：`~/Library/Application Support/PioneersBallad/saves/`。每个世界一个 `.sav` 文件，上一次的存档会留一份 `.bak` 备份
- 写到一半断电、文件损坏都不会让游戏崩溃，标题界面会显示「存档损坏」
- 以前用临时名「星壤纪元」时创建的世界，打开标题界面时会自动搬过来

### 14.2 窗口和全屏

- 游戏启动时窗口是**最大化**的，画面会自动缩放填满窗口，任何分辨率、任何比例都可以
- 按 **F11**（或 Ctrl+Cmd+F、Alt+Enter）切换**全屏**；标题界面上也有「全屏」按钮
- **小窗口、小屏幕也能玩**（最小 800×500）：画面最多缩到 85%，再小就不缩了，界面会自己重新排版——屏幕宽时制作栏在背包右边，窄时放到下面，放不下的用滚轮翻页

## 15. 常见问题

**Q：天黑了什么都看不见？**
在地表晚上会暗一些，但能看清。在地下，没有光的地方是全黑的——放火把（1 个木材做 3 个），或者戴萤石项链、喝萤光药水。

**Q：挖矿的时候只冒火星，挖不动？**
你的镐等级不够。看 [6.2 镐的等级](#62-镐的等级最重要的进度)，先去做更好的镐。

**Q：制作栏里的配方是灰色的，点了没反应？**
材料不够，或者不在对应的制作站旁边（5 格以内）。鼠标指着它，会告诉你差什么。

**Q：挖到的东西没进背包？**
现在东西会先掉在地上，走过去就会自动捡起来。如果走过去也捡不起来，说明**背包满了**，扔掉一些不要的东西（右键或 Q）。

**Q：迷路了，找不到家？**
做一张**回城卷轴**（工作台：2 个灵晶碎片 + 2 个木材），读一下立刻回到出生点。倒下后也会在出生点复活。

**Q：Boss 召唤不出来？**
看提示：泥沼巨像要在**地表**召唤，灵晶守望者要在**洞穴层或深渊**召唤；同一时间只能有一个 Boss。

**Q：星辉镐做不了？**
它需要**守望者棱晶**，要先打败灵晶守望者。

**Q：被游魂追着打，躲进屋子也没用？**
游魂能穿过地面上的树和墙，但**钻不进地下**。往下挖 5 格以上躲进去，它够不着你，十几秒后就会放弃离开；天亮后它也会消失。

**Q：一直中毒 / 冻伤？**
喝解毒剂马上解除；戴苦根护符免疫中毒、戴毛皮围巾免疫冻伤。

**Q：东西丢出去又被吸回来了？**
自己丢的东西要过 1.2 秒才会被吸回来，丢完走开就好。

**Q：玩的时候偶尔看到一闪一闪的细亮线？**
游戏默认用 macOS 原生的 **Metal** 渲染，并且把画面对齐到整像素，正常不会出现。如果还是有，可以在项目文件夹里用旧的 OpenGL 渲染器启动对比一下：`godot --rendering-method gl_compatibility --path .`；把哪种方式会出现告诉开发者。

**Q：画面太小 / 太大？**
窗口可以随意拖大拖小，画面会跟着缩放；按 F11 全屏。

**Q：我的世界会丢吗？**
游戏会自动保存，关窗口时也会保存，还会多留一份备份。正常使用不会丢。
