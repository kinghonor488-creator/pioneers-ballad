# 星壤纪元 Starsoil（临时名）

一个用 **Godot 4** 从零编写的原创 2D 沙盒冒险游戏：挖矿、建造、探索地下世界、收集各种稀奇的道具。
所有代码和美术都是原创的——像素图全部由代码现场生成，没有使用任何外部素材。

> "星壤纪元"只是临时名字，正式名字由你来起。改名只需改 `project.godot` 里的 `config/name`
> 和 `scripts/game/main.gd` 里的欢迎语。

## 如何运行

1. 安装 Godot 4（已通过 `brew install --cask godot` 安装 4.7.2，位置 `/Applications/Godot.app`）。
2. 打开 Godot → 项目管理器里点 **导入** → 选择本文件夹里的 `project.godot`。
   （也可以直接双击 `project.godot`，或在终端运行 `godot --path /Users/sunyubo/Desktop/泰拉瑞亚 --editor`）
3. 在编辑器里按 **F5** 开始游戏。

不打开编辑器、直接玩：

```bash
godot --path /Users/sunyubo/Desktop/泰拉瑞亚
```

启动后先进入**标题界面**：可以继续已有的世界，或者创建新世界（名字、种子、小/中/大三种尺寸）。
最大的 4200×1200 世界生成约 1 秒，存档约 450 KB，保存和读取都只要几毫秒。

## 存档

- 每个世界一个存档文件，保存世界里的所有方块、背包、饰品、药水增益（含剩余时间）、
  工具的词缀和熟练度、生命果、位置、天数和时间
- **自动保存**：每 5 分钟一次；关闭游戏窗口时也会自动保存
- **手动保存**：游戏中按 **Esc** 打开菜单 → 保存游戏 / 保存并回到标题界面 / 保存并退出
- 存档位置：`~/Library/Application Support/Godot/app_userdata/星壤纪元 Starsoil/saves/`
- 安全措施：先写临时文件再替换，上一份存档保留为 `.bak`；损坏或只写了一半的存档会被识别出来，
  不会让游戏崩溃（标题界面会显示"存档损坏"）

## 操作

| 按键 | 作用 |
| --- | --- |
| A / D 或 ← / → | 左右移动（遇到一格高的台阶会自动跨上去） |
| 空格 / W / ↑ | 跳跃（按得越久跳得越高） |
| 鼠标左键（按住） | 使用快捷栏选中的道具：拿镐/斧时挖掘，拿方块时放置，拿药水时喝，拿炸弹时扔 |
| 1 ~ 0、鼠标滚轮 | 选择快捷栏格子 |
| E / Tab / I | 打开或关闭背包和制作栏 |
| Esc | 关闭背包；没开背包时打开暂停菜单（保存 / 回到标题 / 退出） |
| 背包里左键 | 拿起 / 放下 / 交换道具；拖到右边"饰品"栏即可装备 |
| 背包里右键饰品 | 直接装备 |
| 制作栏左键 | 制作（鼠标悬停可以看材料和需要的制作站） |

## 已实现的内容

**世界**
- 程序化生成的 4200×1200 大世界（同一个种子永远生成同一个世界）
- 分层：天空 → 地表（草地、泥土、沙漠）→ 地下（石头夹泥土）→ 洞穴层（大溶洞）→ 深渊（玄武岩）→ 不可破坏的基岩
- 噪声生成的蜿蜒隧道和大溶洞，以及通往地下的天然洞口
- 6 种矿物（赤铜、铁、硫磺、月银、星辉、熔晶）外加黏土，越深越稀有
- 树木、蘑菇、发光的灵晶簇、散落在地下的**遗迹宝匣**
- 分块渲染：世界切成 32×32 的区块，只渲染摄像机附近的区块，性能稳定

**角色与操作**
- 移动、跳跃、重力、与图块的碰撞，摄像机平滑跟随
- 挖掘有进度（裂纹动画）、有距离限制，挖到的东西直接进背包
- 砍树会把整棵树一起砍倒
- 放置方块（有距离限制、不能凭空悬浮、不能放在自己身上）
- 生命值、摔落伤害、自动回血、死亡后在出生点复活

**特色：丰富的道具系统**（56 种道具、35 个配方）
- **6 档稀有度**：普通 / 优良 / 稀有 / 史诗 / 传说 / 神话，名字和边框颜色随稀有度变化
- **工具词缀**：做出来或开宝匣得到的工具会随机带上词缀，比如"迅捷的铁镐"（挖得更快）、
  "远触的"（够得更远）、"幸运的"（几率双倍掉落）、极稀有的"星选的"；也可能是"笨重的"这种坏词缀
- **重铸**：站在铁砧旁，花 2 个灵晶碎片给选中的工具重新随机词缀
- **工具熟练度**：工具挖得越多等级越高（Lv0~Lv5，每级挖掘力 +6%），格子左上角的 ★ 显示等级
- **饰品栏（3 格）**：羽落护符（免疫摔伤）、疾风靴、弹簧鞋、萤石项链（照明）、矿工手套、
  延伸臂环、活力护符、传说级的旅者星核……效果可以叠加
- **药水增益**：萤光、迅捷、采掘、跃升等，带倒计时显示
- **消耗品**：苹果、烤蘑菇、治疗药水、回城卷轴、生命果（永久 +20 最大生命）
- **炸弹 / 烈性炸药**：扔出去会弹跳，几秒后炸开一片方块
- **制作站**：徒手 → 工作台 → 熔炉 → 铁砧，镐的等级决定能挖哪种矿，形成完整的成长路线：
  燧石镐 → 赤铜镐 → 铁镐 → 月银镐 → 星辉镐 → 熔晶钻头
- **遗迹宝匣**：越深的宝匣掉落越好，是饰品的主要来源

**画面**
- 程序生成的像素图块（每种 4 个变体）、背景墙、道具图标
- 昼夜循环（一天 12 分钟）：天空渐变、日出日落、太阳和月亮、星星、视差远山
- 环境光随时间和深度变化，地下很暗；火把、熔炉、灵晶簇、宝匣会发光

## 项目结构

```
project.godot            Godot 项目配置
scenes/title.tscn        标题界面（游戏的启动场景）
scenes/main.tscn         游戏场景（只挂了 main.gd，其余节点都在代码里创建）
scripts/
  data/tile_db.gd        图块定义（硬度、掉落物、需要的镐等级、发光……）
  data/item_db.gd        道具、配方、词缀、熟练度、宝匣掉落表 —— 加新道具就改这里
  world/world_gen.gd     世界生成
  world/world_data.gd    世界数据（字节数组）
  world/world_renderer.gd 分块渲染和灯光
  world/tile_art.gd      程序生成像素美术
  world/sky.gd           天空背景
  world/tile_cursor.gd   鼠标指向的方块框
  player/player.gd       玩家移动和碰撞
  entities/bomb.gd       炸弹 / blast.gd 爆炸效果
  game/main.gd           游戏主控（挖掘、放置、使用、合成、增益、昼夜）
  game/inventory.gd      背包
  game/save_system.gd    存档文件读写
  game/game_session.gd   标题界面和游戏场景之间传递"玩哪个世界"
  ui/title_menu.gd       标题界面（世界列表、新建、删除）
  ui/hud.gd              界面
tests/smoke_test.gd      自动化冒烟测试
tools/export_art.gd      把生成的像素图导出成 PNG（assets/generated/）
tools/screenshot.gd      开发用截图工具
```

## 测试

```bash
godot --headless --path /Users/sunyubo/Desktop/泰拉瑞亚 -s res://tests/smoke_test.gd
```

会检查：道具/配方数据完整、世界生成结果（分层、矿石、树、宝匣、洞穴比例、基岩、出生点）、
玩家落地/移动/跳跃、挖掘进背包、放置、合成、饰品和药水效果、炸弹、游戏主循环无报错，
以及存档读档（世界、背包、词缀、熟练度、增益、位置原样恢复，损坏/截断的存档能识别，
从标题界面新建世界 → 进游戏 → 存档回标题的完整流程）。
加上 `-- --full` 还会测一次完整尺寸世界的生成时间。全部通过时退出码为 0。
